## 1. Product Overview
Pandas数据分析实战训练营是一个专业的在线学习平台，通过浏览器即可运行Python代码进行数据分析学习。
- 为数据分析师、学生和编程爱好者提供交互式学习体验
- 让用户无需安装复杂环境即可学习Pandas和数据分析技能

## 2. Core Features

### 2.1 User Roles
无需区分角色，所有用户都拥有完整访问权限。

### 2.2 Feature Module
1. **项目列表页**：展示10个精选训练项目，包含项目简介和难度等级
2. **训练工作区**：代码编辑器、输出面板、训练步骤指引、数据集预览

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 项目列表页 | Hero区域 | 展示平台名称、核心价值和开始学习按钮 |
| 项目列表页 | 项目卡片网格 | 以卡片形式展示所有训练项目，包含项目图标、标题、简介、难度和预计学习时间 |
| 训练工作区 | 左侧信息栏 | 项目信息、训练步骤指引、数据集预览 |
| 训练工作区 | 右侧工作区 | 代码编辑器、输出面板、工具栏（运行、重置） |

## 3. Core Process
用户进入平台后，浏览项目列表选择感兴趣的项目，进入训练界面按照步骤指引进行学习，在代码编辑器中编写和运行代码，查看输出结果和数据可视化图表。

```mermaid
flowchart LR
  A[进入平台] --> B[浏览项目列表]
  B --> C[选择训练项目]
  C --> D[进入训练界面]
  D --> E[阅读训练步骤]
  E --> F[编写/修改代码]
  F --> G[运行代码]
  G --> H{查看结果}
  H -->|成功| I[继续学习]
  H -->|失败| F
  I --> J[完成项目，返回列表]
```

## 4. User Interface Design

### 4.1 Design Style
- **主色调**：深靛蓝色 (#1a365d) 搭配亮青色 (#319795)
- **辅助色**：柔和粉色 (#fce7f3)、淡蓝色 (#ebf8ff)
- **按钮风格**：圆角矩形，微妙阴影，悬停时有轻微上浮效果
- **字体**：使用 Inter 作为主要字体，标题使用更有特色的 Playfair Display
- **布局风格**：卡片式布局，清晰的视觉层次，充足的留白
- **图标风格**：简洁线性图标，使用 lucide-react

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 项目列表页 | Hero区域 | 渐变背景，大标题，副标题，CTA按钮，微妙动画效果 |
| 项目列表页 | 项目卡片网格 | 2列网格布局，卡片悬停效果，项目信息清晰展示 |
| 训练工作区 | 左侧信息栏 | 固定宽度侧边栏，分组信息卡片，滚动内容区域 |
| 训练工作区 | 右侧工作区 | 垂直分割布局，代码编辑器深色主题，输出面板清晰展示 |

### 4.3 Responsiveness
桌面优先设计，适配平板和移动设备。
- 桌面端：完整三栏/两栏布局
- 平板端：响应式调整宽度比例
- 移动端：垂直堆叠布局，优化触控操作

### 4.4 动画与交互
- 页面加载时的淡入动画
- 元素进入视口时的滑入效果
- 卡片悬停时的上浮和阴影增强
- 按钮点击时的波纹反馈
- 代码运行时的加载状态动画
